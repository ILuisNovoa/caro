# Nuestra historia
<!-- impeccable:product-schema 1 -->
## Platform
web
## Purpose
Un regalo para la novia del usuario: un libro de fotos e historias, responsive para celular y PC. Rosado como color principal. Portada con selección de canciones y elección aleatoria.
## Stack
HTML, CSS y JavaScript estáticos, elegido para esta primera versión editable.
## Evidence
El usuario aprobó comenzar con la propuesta y cambiarla al verla. Nombres, fotos, canciones y fechas pendientes. Los textos son una propuesta, no hechos de su relación.
